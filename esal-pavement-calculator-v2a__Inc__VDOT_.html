VDOT Highway Classification & Default Parameters VDOT Geotechnical & Pavement Design Manual §3.4.3
Select highway classification to apply VDOT standard design values for PCC rigid pavement. VDOT defaults: Sc = 650 psi, Ec = 5,000,000 psi, k = 250 pci (or derived from CBR as Mr/19.4), Cd = 1.0, J = 3.2 (asphalt shoulder). Values can be further modified after applying.
VDOT k-value: If subgrade resilient modulus is available, use k = MR / 19.4. If k from back-calculation or MR/19.4 exceeds 500 pci, cap at 500 pci. Use the k Override field to enter a site-specific value.
